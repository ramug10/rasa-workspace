# Quality Gates

Each sprint plan must include these gates before merge.

## Required sections

1. Definition of Done.
2. Risk register with owner and mitigation.
3. Test matrix (happy path, error path, edge cases).
4. Rollback strategy for critical changes.

## Merge readiness checklist

- QA sign-off documented.
- No blocker defects open.
- All acceptance criteria are checked.
- Deployment notes and rollback steps are present.
