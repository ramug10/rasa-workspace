# Brainstorm Format

Use this prompt structure to enforce real debate:

1. Name each role explicitly.
2. Define each role's tendency and bias.
3. Require at least two disagreements.
4. Produce outputs into separate files in `docs/brainstorm/`.

## Output files

- `docs/brainstorm/01-free-ideation.md`
- `docs/brainstorm/02-discussion.md`
- `docs/brainstorm/03-concept-A.md`
- `docs/brainstorm/04-team-vote.md`
- `docs/brainstorm/05-summary.md`
