# Changelog

All notable changes to this workspace plugin are documented in this file.

## 1.0.0 - 2026-07-10

- Introduced `orchestration.config.yaml` as the reusable orchestration contract.
- Added JSON schema at `schema/orchestration.config.schema.json`.
- Added reusable team profiles in `profiles/` (`web-app`, `api-only`, `data-app`).
- Modularized orchestration guidance into `skills/ai-team-orchestration/references/modules/`.
- Added reusable bootstrap templates under `templates/`.
- Added validation checklist for required governance artifacts.
- Fixed wording and typo quality issues in orchestration docs.
